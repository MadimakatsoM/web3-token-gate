# Web3 Token-Gated Community Pass

A lightweight Web3 authentication prototype that combines user registration with wallet connection and digital asset verification to grant gated community access.

## The Problem
Online communities and gaming groups need a simple way to verify digital asset ownership before granting members access to exclusive perks or lobbies.

## Features
- **User Registration:** Captures a member username before wallet verification.
- **Wallet Connection:** Supports MetaMask (`window.ethereum`) with a built-in Demo Wallet mode for easy testing.
- **Token-Gated Access Control:** Checks wallet addresses against verified pass holders and unlocks community access.

## How to Run
1. Clone the repository: `git clone https://github.com/MadimakatsoM/web3-token-gate.git`
2. Open `index.html` in any modern web browser.
